# 🚀 AI Workflow Automation Platform

An AI-powered workflow automation platform built using React and Node.js.  
This application allows users to create and execute workflows with a simple and interactive UI.

---

## 📌 Features

- Create workflows dynamically  
- Run workflows with one click  
- Unique workflow ID generation  
- Fast and responsive UI  
- Full-stack integration (React + Node.js)  

---

## 🛠️ Tech Stack

Frontend:
- React.js
- HTML, CSS, JavaScript

Backend:
- Node.js
- Express.js

## ⚙️ Setup Instructions

### 1. Clone the repository

git clone https://github.com/YOUR_USERNAME/YOUR_REPO_NAME.git  
cd YOUR_REPO_NAME  

---

### 2. Install dependencies

Frontend:
cd client  
npm install  

Backend:
cd ../backend  
npm install  

---

### 3. Run the project

Start backend:
node app.js  

Start frontend:
cd ../client  
npm start  

---

## 🌐 Access the App

Open in browser:
http://localhost:3000
